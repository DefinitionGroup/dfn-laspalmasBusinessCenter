# Las Palmas Business Center — logo refresh

The recommended logo is `las-palmas-business-center-logo.svg`.

It keeps the source logo’s Atlantic-blue architectural arc, golden
sun/horizon, and two-line uppercase name while simplifying the geometry and
spacing for a more contemporary identity.

## Production notes

- All lettering is converted to vector outlines. No font files are required.
- The SVG uses a transparent background and a `1200 × 360` viewBox.
- The mark uses closed filled geometry for broad browser, print, presentation,
  and vector-editor compatibility.
- The source reference was
  `/Users/martin/Desktop/logo_business_center.png`.
- The three `alternate-*.svg` files are exploratory identity directions, not
  replacements for the recommended master.

## Palette

- Atlantic: `#075D7A`
- Atlantic Deep: `#073B4C`
- Solar: `#F4A700`

The SVG exports are generated deterministically by
`scripts/build-logo-refresh.mjs`.
